## ▶️ How to Run a Java Program

1. Install JDK (Java Development Kit).
2. Set up the Java environment variables.
3. Open the terminal in the folder containing the Java file.
4. Compile the Java program:

```bash
javac Program.java
```

5. Run the Java program:

```bash
java Program
```

**Note:** The filename and public class name must match.
